XPath reference (transcription of attached slides)

- Types of XPATH

  There are two types of XPath: Absolute XPath and Relative XPath.

  "Think of XPath like giving directions to find something on a webpage,
  just like finding a house in a city."

- Example: Simple HTML Script

  <html>
    <body>
      <div>
        <h1>Welcome to My Website</h1>
        <p id="intro">This is a sample paragraph.</p>
        <button>Click Me</button>
      </div>
    </body>
  </html>

- Absolute XPath

  Absolute xpath starts from the root (html) and follows the complete path.
  Examples from slide:
    /html/body/div/h1
    /html/body/div/p1

- Relative XPath

  //p    - selects any <p> element in the page.
  Using attribute (id) for more precision:
    //p[@id='intro']

- Notes / Recommendation

  - Absolute XPath: /html/body/div/p (full path — fragile)
  - Relative XPath: //p[@id='intro'] (flexible, recommended)
