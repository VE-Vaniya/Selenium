1️⃣ Dynamic & Lazy-Loaded Content

Example: Infinite scrolling feeds (like Twitter or Instagram), content that appears only when you scroll, or elements loaded via AJAX.

Problem: Elements may not exist immediately, so find_element fails.

Solution:

Use Explicit Waits (WebDriverWait) instead of static sleep().

Wait for visibility or presence of elements.

Handle lazy-loaded content by scrolling programmatically.

Code snippet:

from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

# Wait up to 10 seconds for element to appear
element = WebDriverWait(driver, 10).until(
    EC.presence_of_element_located((By.CSS_SELECTOR, ".dynamic-element"))
)

2️⃣ Shadow DOM / Web Components

Example: Modern frameworks like React, Angular, or Lit often use shadow DOM, which hides inner elements from normal Selenium selectors.

Problem: find_element cannot see elements inside the shadow root directly.

Solution:

Use JavaScript execution to pierce shadow DOM.

# Get shadow root element
shadow_host = driver.find_element(By.CSS_SELECTOR, "custom-element")
shadow_root = driver.execute_script("return arguments[0].shadowRoot", shadow_host)

# Now find element inside shadow DOM
inner_elem = shadow_root.find_element(By.CSS_SELECTOR, "button#submit")
inner_elem.click()

3️⃣ Iframes & Nested Frames

Example: Ads, login widgets, embedded videos, and chatbots often live in iframes.

Problem: Selenium can only see elements in the current frame.

Solution:

Switch to the frame first, then locate elements.

Switch back to default content afterward.

iframe = driver.find_element(By.CSS_SELECTOR, "iframe#ad-frame")
driver.switch_to.frame(iframe)
driver.find_element(By.ID, "close-button").click()
driver.switch_to.default_content()

4️⃣ Dynamically Changing IDs / Classes

Example: Many sites generate random or session-based IDs every page load.

Problem: By.ID or By.CLASS_NAME fails.

Solution:

Use stable locators: text, CSS hierarchy, XPath with contains(), starts-with(), ends-with().

Avoid exact IDs if they’re dynamic.

# XPath using partial attribute match
button = driver.find_element(By.XPATH, "//button[contains(@id, 'submit_')]")
button.click()

5️⃣ Popups & Modals (Non-Standard)

Example: Some modals are not JS alerts, but HTML overlays.

Problem: .switch_to.alert won’t work.

Solution:

Treat modals like normal elements, maybe wait for visibility.

Sometimes you need Actions chains to click hidden close buttons.

from selenium.webdriver.common.action_chains import ActionChains

modal_close = driver.find_element(By.CSS_SELECTOR, ".modal-close")
actions = ActionChains(driver)
actions.move_to_element(modal_close).click().perform()

6️⃣ Single Page Applications (SPA)

Example: React, Angular, Vue.js websites. URL doesn’t change, but content updates dynamically.

Problem: Selenium might try to access elements before they exist, because page reload never happens.

Solution:

Wait for elements using Explicit Waits.

Use EC.staleness_of() or EC.element_to_be_clickable() to handle dynamically changing DOM.

from selenium.webdriver.support import expected_conditions as EC

old_element = driver.find_element(By.CSS_SELECTOR, ".item")
# Wait until the old element is replaced by new content
WebDriverWait(driver, 10).until(EC.staleness_of(old_element))

7️⃣ Infinite Scroll & Lazy Images

Example: Social media, e-commerce product lists, image galleries.

Problem: Selenium doesn’t scroll automatically; lazy-loaded images/elements don’t appear.

Solution:

Scroll using JavaScript or ActionChains.

Keep checking if new elements appeared.

driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
time.sleep(2)  # wait for new content

8️⃣ CAPTCHA & Bot Detection

Example: Sites like Google, banking portals, or ticketing platforms.

Problem: Cannot bypass easily — bot detection triggers.

Solution:

Usually, you cannot fully automate bypass legally.

Use test environments without CAPTCHA or manual verification steps.
